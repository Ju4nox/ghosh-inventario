Lista de precios Excel

Se busca la tabla con ARTICULO y UNIDAD X CAJA. Solo se reciben artículos con Código I o Código B único; las filas sin identificación única se omiten.

FilaCódigo IArtículoUnidades inicialesLote generadoVencimientoEstado
El archivo no contiene lotes. Se creará un código interno por artículo y fila, visible en el historial. Esto no sustituye el lote real del proveedor. La cantidad recibida será exactamente UNIDAD X CAJA. Los decimales se redondean a la precisión admitida; para artículos nuevos, UNIDAD X CAJA se redondea a unidades enteras. Los artículos existentes suman stock. Si el Código I no existe, se crea el producto con ARTICULO, PESO, UNIDAD X CAJA y PRECIO X UNIDAD; para crearlo se requiere Código I único. Los nuevos se crean en Lista de precios, como unidad y sin trazabilidad activada.

Revisaremos las filas antes de guardar. Si hay un dato inválido, no se registrará ninguna recepción.
